# 影像检查（画像検査）功能说明

> **注意**: 影像检查功能实现在 `t_check_ms.aspx`（检查明细页面）中，而非 `m_temp_name.aspx`（模板名称MS页面）。

---

## 1. 功能概述

影像检查（画像検査）功能用于与外部业者影像系统联动，对产品进行自动影像检查。用户在检查明细页面点击按钮发起影像检查准备，系统将检查任务发送给业者系统，业者系统检查完成后将结果返回，系统自动将结果填入检查明细的对应项目。

---

## 2. 业务流程

| 步骤 | 操作 | 说明 |
|------|------|------|
| 0 | **准备** | 用户在画面点击"1.准备影像检查"按钮，将检查对象信息写入 `m_yxld` 表 |
| 1 | **接口1（业者→系统）** | 业者系统调用 API 获取待检查的 CD/No 信息 |
| 2 | **接口2（系统→业者）** | 业者系统检查完成后，调用 API 将检查结果写回 `m_yxld` 表 |
| 3 | **结果获取（轮询）** | 前端每4秒轮询一次结果，获取成功后自动填入 GridView 明细 |

## 4. 前端逻辑（t_check_ms.aspx.js）

### 4.1 按钮点击事件（#btnZB.click）

```javascript
$("#btnZB").click(function () {
    // 1. 获取当前工单信息
    var cd = $("#lblCode").text();       // 制品CODE
    var no = $("#lblMake_no").text();     // 工单号
    var line = $("#hidPlanLineId").val(); // 生产线
    
    // 2. 调用后台API【准备】
    var rtv = WebMethod("api", "SetJunbiYXLD", JSON.stringify({...}));
    
    // 3. 准备成功（返回时间戳）→ 开始轮询结果
    if (rtv.length == 23) {  // 返回的是数据库时间字符串 yyyy-MM-dd HH:mm:ss.fff
        $("#hidYXLD_START_TIME").val(rtv);  // 记录开始时间
        GetYXLD_RLT(cd, no, line);          // 启动轮询
    }
});
```

### 4.2 结果轮询（GetYXLD_RLT）

```javascript
var putYXLD_CNT = 0;  // 轮询计数器

var GetYXLD_RLT = function (cd, no, line) {
    // 调用API检查结果
    var rtv = WebMethod("api", "GetYXLD_RLT", JSON.stringify({
        no: no, cd: cd, line: line,
        start_time: $("#hidYXLD_START_TIME").val()
    }));
    
    // 超时判定：8000次 × 4秒 ≈ 80分钟
    if (putYXLD_CNT > 8000) {
        // 超时终止
        return;
    }
    
    if (rtv == "NEXT") {
        // 还没有结果，4秒后继续轮询
        putYXLD_CNT++;
        setTimeout(function () {
            GetYXLD_RLT(cd, no, line);
        }, 4000);
    } else if (rtv == "NG") {
        // 检查失败
    } else {
        // 成功获取结果，解析并填入明细
        // 格式：检查项目名1,结果1,检查项目名2,结果2,...
        var arr = rtv.split(",");
        for (i = 0; i <= arr.length - 1; i = i + 2) {
            var km = arr[i];         // 检查项目名
            var yx_rlt = arr[i + 1]; // 结果值
            
            // 在GridView中查找匹配的检查项目
            $("#gvMs").find("tr").each(function () {
                var kmTxt = tr.attr("chk_km_name");
                if (kmTxt.indexOf(km) >= 0) {
                    // 判断逻辑：
                    if (km包含'SW'或'DH') {
                        // 直接填入数值，用函数验证
                    } else if (结果 == "0") {
                        // 结果 = NG
                    } else {
                        // 结果 = OK
                    }
                }
            });
        }
    }
}
```

#### 轮询参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 轮询间隔 | 4秒 | setTimeout 设定 |
| 最大轮询次数 | 8000次 | × 4秒 ≈ 80分钟 |
| 超时信息 | "80分钟未获得结果，终止影像检查结果获取" | |

#### 结果解析逻辑

结果字符串格式: `检查项目名1,结果1,检查项目名2,结果2,...`

| 条件 | 判定结果 | 说明 |
|------|----------|------|
| 检查项目包含 `SW` 或 `DH` | 填入测量值，用公式验证 | 数值型检查 |
| 结果值为 `0` | NG | 不合格 |
| 结果值不为 `0` | OK | 合格 |

### 4.3 轮询自动启动条件

```javascript
if ($("#hidYXLD_START_TIME").val() != '') {
    // 页面加载时如果已有开始时间，自动启动轮询
    GetYXLD_RLT(yxld_cd, yxld_no, yxld_line);
}
```

## 5. 后端API（App_Code/api.vb）

### 5.1 SetJunbiYXLD - 准备影像检查

| 项目 | 说明 |
|------|------|
| **WebMethod** | `SetJunbiYXLD(no, cd, line, user)` |
| **调用时机** | 用户点击"1.准备影像检查" |
| **功能** | 将检查对象写入 `m_yxld` 表，记录日志到 `m_yxld_log` |
| **返回值** | 数据库当前时间字符串（yyyy-MM-dd HH:mm:ss.fff） |

**SQL操作**:
1. 删除 `m_yxld` 中同 CD/NO/Line 的旧记录
2. 插入新记录（初始状态：txt = ''）
3. 删除10天前的日志
4. 插入日志（状态：`0.准备`）

### 5.2 GetYXLD - 接口1（业者取得待检查数据）

| 项目 | 说明 |
|------|------|
| **WebMethod** | `GetYXLD(line)` |
| **调用方** | 外部业者影像系统 |
| **功能** | 取得指定生产线的最新待检查数据 |
| **返回值** | 成功: `no,cd,line` / 失败: `NG:没有待检查数据！！` |

### 5.3 SetYXLD - 接口2（业者返回检查结果）

| 项目 | 说明 |
|------|------|
| **WebMethod** | `SetYXLD(no, cd, line, txt)` |
| **调用方** | 外部业者影像系统 |
| **功能** | 将影像检查结果写回 `m_yxld.txt` 字段 |
| **txt格式** | `检查项目名1,结果1,检查项目名2,结果2,...` |
| **返回值** | `OK` 或 `NG:错误信息` |

**示例txt内容**:
```
捆包标签,1,有部品17MC,0,胶带数量,1
```

### 5.4 GetYXLD_RLT - 前端轮询结果

| 项目 | 说明 |
|------|------|
| **WebMethod** | `GetYXLD_RLT(no, cd, line, start_time)` |
| **调用方** | 前端JS轮询 |
| **功能** | 检查 `m_yxld` 表中是否已有结果（txt != '' 且更新时间 > start_time） |
| **返回值** | `"NEXT"` : 尚无结果 / `"NG"` : 异常 / `结果字符串` : 成功 |

**线程安全**：使用 `SyncLock Padlock` + `Threading.Thread.Sleep(10)` 确保并发安全

## 6. 数据库表

### 6.1 m_yxld - 影像联动主表

| 字段 | 类型 | 说明 |
|------|------|------|
| no | varchar | 工单号 |
| cd | varchar | 制品CODE |
| line | varchar | 生产线 |
| txt | nvarchar(max) | 影像检查结果 |
| ins_date | datetime | 插入时间 |
| upd_date | datetime | 更新时间 |

### 6.2 m_yxld_log - 影像联动日志表

| 字段 | 类型 | 说明 |
|------|------|------|
| no | varchar | 工单号 |
| cd | varchar | 制品CODE |
| line | varchar | 生产线 |
| txt | nvarchar(max) | 内容 |
| ins_date | datetime | 插入时间 |
| kbn | nvarchar | 状态区分（`0.准备` / `1.接口1_OK` / `1.接口1_NG` / `2.接口1_OK` / `2.接口1_NG` / `3.结果OK` / `3.结果NEXT` / `3.结果NG`） |

```
  [用户点击"1.准备影像检查"]
         │
         ▼
  SetJunbiYXLD → m_yxld登録 (0.准备)
         │
         ├─────────────────────┐
         │                     │
         ▼                     ▼
  前端轮询开始          [业者系统]
  GetYXLD_RLT           GetYXLD(接口1)

         │                     │
         │                     ▼
         │              [业者检查完成]
         │              SetYXLD(接口2)
         │              结果写入txt
         │                     │
         │◄────────────────────┘
         ▼
  检测到结果(txt != '')
         │
         ▼
  解析结果字符串 → GridView自动填入
  检查项目匹配 → OK/NG判定 → 结果着色
```

## 8. 关键参数说明

| 参数 | 值 | 说明 |
|------|-----|------|
| 轮询间隔 | 4000ms (4秒) | 前端轮询频率 |
| 最大轮询次数 | 8000次 | 约80分钟超时 |
| 开始时间格式 | yyyy-MM-dd HH:mm:ss.fff | 23位时间戳字符串 |
| 结果分隔符 | `,`（逗号） | 成对出现：项目名,结果 |
| 线程同步 | SyncLock + Sleep(10ms) | 防并发处理 |

---

## 9. 注意事项

1. **`t_check_ms.aspx`** 是影像检查功能的实际载体，`m_temp_name.aspx` 不包含此功能
2. 模拟测试接口（btnSv1/btnSv2）仅供开发调试，生产环境隐藏
3. 轮询机制最大支持约80分钟，超时后需用户重新点击准备按钮
4. 结果解析支持三种模式：数值型(SW/DH)、0判定、非0判定
5. 业者系统接口（GetYXLD/SetYXLD）需要在系统外部实现调用
